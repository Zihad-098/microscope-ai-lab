# Microscope AI Lab

## About
An educational computer vision project for microscopic
fungal and bacterial image classification.

## Objectives
- Explore and prepare a microscopy image dataset.
- Train and evaluate deep learning models.
- Compare classification performance.
- Build an image prediction application.
- Visualize model predictions using Grad-CAM.

## Technology Stack
- Python
- TensorFlow / Keras
- NumPy and Pandas
- FastAPI
- Git and GitHub

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Project Status
Planning and initial setup.

## Disclaimer
This project is for educational and research purposes.
It is not a clinically validated diagnostic system.
